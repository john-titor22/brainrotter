# Terms of Service — Brainrotter

Brainrotter is a personal, non-commercial project that generates short-form
video content and publishes it to the developer's own social media accounts
via each platform's official API, using the developer's own API credentials.

- The app is used solely by its developer for their own accounts.
- No user data from third parties is collected, stored, or shared.
- Content is generated locally and posted only to accounts the developer
  owns and controls.

Contact: see the repository at
https://github.com/john-titor22/brainrotter for more information.
